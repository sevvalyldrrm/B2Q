# 🚀 B2Q Development Workflow (Light Version)
---
## 🔧 1. Main Güncelle

```bash
git checkout main
git pull origin main
```
---
## 🌿 2. Branch Aç
```bash
git checkout -b feature/feature-name
```
---
## 💻 3. Geliştir & Commit
```bash
git add .
git commit -m "feature: açıklama"
```
---
## 🌐 4. Push
```bash
git push origin feature/feature-name
```
---
## 🔀 5. PR Aç
* GitHub’dan PR aç
* Review zorunlu değil
* Kendin de merge edebilirsin
---
## 🔄 6. Güncelle
```bash
git checkout main
git pull origin main
```
---
## ⚠️ Notlar

* `.env` asla pushlanmaz
* Küçük commitler yapılır
* Branch isimleri anlamlı olur
